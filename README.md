# Unicorn SP

An Android emulator frontend built with Kotlin, Jetpack Compose, and LibretroDroid (`compileSdk` / `targetSdk` 36).

## Project Details
- **Application ID:** `com.hoodedunicorn.unicornsp`
- **Namespace:** `com.unicornemulator.app`
- **Core Engine:** `LibretroDroid` (via JitPack)
- **License:** GNU General Public License v3.0

## Building
1. Open the project in Android Studio.
2. Allow Gradle to sync dependencies (including JitPack for `LibretroDroid`).
3. Build and run on a device or emulator.
